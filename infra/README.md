# Telemetry backend stack (M1)

OpenTelemetry Collector → Prometheus (metrics), Tempo (traces), Loki (logs) → Grafana.

## Run

```sh
cd infra
docker compose up -d
docker compose ps
```

| Service | URL / endpoint | Notes |
|---|---|---|
| Grafana | http://localhost:3000 | Anonymous admin (local use only). Data sources and the "Endpoint Telemetry" folder are provisioned. |
| OTel Collector | `localhost:4317` (gRPC), `localhost:4318` (HTTP) | Where agents send OTLP. Health: http://localhost:13133 |
| Prometheus | http://localhost:9090 | Receives metrics by push on `/api/v1/otlp` (OTLP receiver). |
| Tempo | http://localhost:3200 | Query API. OTLP ingest is internal only. |
| Loki | http://localhost:3100 | Receives logs on `/otlp`. Takes about 20s after start to report ready. |

Agents in the Parallels VM use the Mac's shared-network address instead of `localhost`: `http://10.211.55.2:4317`.

## Smoke test

```sh
docker compose --profile test run --rm telemetrygen-traces
docker compose --profile test run --rm telemetrygen-logs
docker compose --profile test run --rm telemetrygen-metrics   # runs for 30s
```

Then in Grafana → Explore:

- Prometheus: `gen{service_name="telemetrygen"}`
- Loki: `{service_name="telemetrygen"}`
- Tempo: search `service.name = telemetrygen`

## Dashboard

Grafana → Dashboards → Endpoint Telemetry → **Endpoint Overview** (http://localhost:3000/d/endpoint-overview), filterable by OS and host:

- **Fleet:** hosts reporting, average CPU and memory, fullest volume, process count, late agents, and a per-host table.
- **Device performance:** CPU busy, memory used, memory by state, disk space, disk and network throughput.
- **App performance:** top apps by CPU, memory and disk I/O.
- **Agent health:** collector run times, failed cycles, the agent's own CPU, and agent logs (linked to traces).

`grafana/dashboards/endpoint-overview.json` is generated by `grafana/gen_dashboard.py`:

```sh
python3 grafana/gen_dashboard.py > grafana/dashboards/endpoint-overview.json
```

Grafana reloads the file within about 10 seconds. Edits made in the Grafana UI are allowed but are overwritten the next time the file is regenerated.

## Label mapping

OTLP resource attributes become labels with dots replaced by underscores (`host.name` → `host_name`).

- Prometheus promotes the attributes listed under `otlp.promote_resource_attributes` in `prometheus/prometheus.yml`. Others are on the `target_info` series.
- Loki indexes `service.name` and the defaults, plus `host.name` and `os.type` (`loki/loki.yaml`). Other attributes are structured metadata.

## Reset

```sh
docker compose down -v   # also deletes all stored data
```
